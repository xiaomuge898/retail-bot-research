### 编码文本 和 解码数组
- 请在 `proprietary_code.js` 文件内执行
```js
// 编码文本 -> 数组 (注意：是文本，不是数值，如果填写数值，解码后的值可能对不上)
var f = "7673048502411395348"
var text = proprietary_code.fromValue(f)
console.log(text)
// 编码后：{ low: -1701641964, high: 1786520821, unsigned: false }

// 解码数组 -> 文本内容
var f = { low: -1701641964, high: 1786520821, unsigned: false }
var data = proprietary_code.fromValue(f).toString()
console.log(data)
// 解码后："7673048502411395348"
```

### 定位websocket加解密位置
- 打开发信页面、打开F12面板、筛选socket类型、找到ws链接
- 堆栈找到open点击跳转
- 在当前跳转页面的源码内找到 `send` ，打上断点，随便发送一个信息，或刷新页面都可以触发断点
- 断住后，堆栈找 `sendByWs` 这里就是构造体(发信模板)加密的核心位置
- 解密位置在加密源码位置的下面，可以来回找一下，没有那么难
- webpasck 直接扣代码即可
